# 校园生活系统 · Campus Life System

一站式智慧校园生活服务平台，覆盖学生、教职工、管理员三大角色，集成宿舍、餐饮、报修、门禁、社交、考勤、办公、运维、财务等全场景服务。

## 技术栈

- 纯原生 HTML5 + CSS3 + JavaScript（无构建依赖，浏览器直接打开即可运行）
- CSS 自定义变量实现主题系统（亮/暗模式 + 三角色彩）
- 内联 SVG 图标库，零图片依赖
- 模块化 JS：`mock.js`（数据层）+ `app.js`（核心层）

## 设计风格

采用 **Minimalist Modern** 视觉体系：
- Electric Blue 渐变主色 + 角色化主题色（学生蓝 / 教职工绿 / 管理员紫）
- Plus Jakarta Sans + Inter 双字体配对
- 卡片化布局 + 微动效 + 玻璃拟态 + 点阵纹理

## 功能模块

### 学生端（6 个模块）
| 模块 | 功能要点 |
|------|---------|
| 概览 | 统计卡片、快捷功能、工单、菜单、社交动态 |
| 宿舍管理 | 宿舍信息、室友、水电费趋势、卫生检查、账单导出 |
| 餐饮服务 | 校园卡余额、食堂导航、今日菜单、在线点餐、订单记录 |
| 后勤报修 | 工单列表、4 步进度条、紧急程度、催单、新报修弹窗 |
| 门禁出行 | 动态通行码、通行记录、异常提醒、校门导航 |
| 校园社交 | 发布动态、点赞评论、活动报名、推荐社群、失物招领 |

### 教职工端（5 个模块）
| 模块 | 功能要点 |
|------|---------|
| 概览 | 实时时钟、考勤状态、快捷办公、通知、报修 |
| 考勤打卡 | 实时打卡、考勤日历、月度统计、最近记录 |
| 通知下发 | 通知模板、发布弹窗、阅读率追踪、多渠道推送 |

| 场地物资借用 | 会议室预约、物资库存、借用归还管理 |

### 管理员端（7 个模块）
| 模块 | 功能要点 |
|------|---------|
| 概览 | 用户增长、系统健康度、待处理工单、实时日志、服务状态 |
| 用户管理 | 多维筛选、用户列表、新建用户、冻结/解冻、导出 |
| 工单运维 | SLA 监控、派工、类型分布、处理人工作量 |
| 财务对账 | 收支概览、收入构成环形图、收支趋势、流水明细 |

| 拓展增值 | 应用市场、OpenAPI 列表、SDK 示例、接口调用演示 |

### 拓展增值接口（预留）
系统内置拓展注册器 `CAMPUS.extensions`，支持：
- `register(ext)` — 注册自定义拓展
- `invoke(name, ...args)` — 调用拓展接口
- `list()` — 列出已注册拓展

预置 8 个拓展应用（智能问答、校园电商、心理咨询、课表导入、地图导航、电子学生证、校友平台、能源管理），并已在「拓展增值」页面提供在线调用演示。

直接用浏览器打开 `index.html` 即可，无需任何构建或服务端。

顶栏主题按钮可一键切换亮/暗模式，偏好持久化至 `localStorage`。

## 特性亮点

- **三端统一 Shell**：侧边栏 + 顶栏 + 内容区，角色化主题色自动注入
- **零依赖**：所有 HTML/CSS/JS 原生编写，无 npm、无打包、无 CDN
- **响应式**：桌面/平板/手机三档断点，移动端侧边栏抽屉化
- **可访问性**：语义化标签、键盘可达、focus ring、aria 友好
- **数据驱动**：所有页面数据来自 `mock.js`，便于对接真实后端
- **组件化**：按钮/卡片/表格/模态/Toast/标签/进度条/时间线等通用组件
- **动效系统**：fadeUp / scaleIn / pulse / float / shimmer 等关键帧
- **暗色模式**：CSS 变量驱动，全组件适配
